# Sillage pour Android

Distribution de l’application personnelle Sillage : commandes vocales anglaises reconnues localement, contrôles médias, minuteurs et diagnostic partageable.

[Télécharger la dernière version](https://github.com/maxis0191/sillage-android/releases/latest)

Les fichiers APK sont signés et contiennent le modèle de reconnaissance. Aucun compte ni accès Internet n’est requis par l’application. Les commandes médias dépendent des fonctions exposées par chaque lecteur. Le micro du téléphone est privilégié ; les écouteurs, la précision dans le bruit et l’autonomie restent à vérifier sur le téléphone réel.

Ce dépôt sert uniquement à la distribution des APK et de leurs empreintes. La clé de signature et les fichiers privés ne sont pas publiés.
